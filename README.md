# CodeAlpha Hangman Game

A beginner-friendly, text-based Hangman game written in Python.

## Features
- Randomly selects one of five predefined words.
- Lets the player guess one letter at a time.
- Allows up to six incorrect guesses.
- Checks invalid and repeated inputs.

## Requirements
- Python 3
- No external packages required.

## Run
```bash
python hangman_game.py
```

## Concepts
`random`, lists, strings, `while` loop, `if-else`, and console input/output.
